# 🎮 Gojo Platformer Game

Платформер с персонажем Годжо Сатору в стиле Funko Pop!

## Особенности

- ✨ Funko Pop дизайн персонажа
- 🏃 Анимация бега в стиле Silksong
- 🦘 Прыжки с эффектом squash/stretch как в Mario
- ⚔️ Боевая система
- 💊 Система инвентаря и зелий
- 🛡️ Броня
- 📱 Поддержка мобильных устройств

## Управление

### Клавиатура:
- **Стрелки / WASD** - Движение
- **Пробел / W** - Прыжок
- **Z / X** - Атака
- **E** - Использовать зелье
- **1-5** - Выбор слота хотбара
- **P** - Пауза
- **R** - Возрождение
- **ESC** - Вернуться в меню
- **S** - Начать игру из меню

### Мобильные:
- Виртуальный джойстик - Движение
- Кнопка JUMP - Прыжок
- Кнопка ATTACK - Атака

## Технологии

- Django 5.0.1
- HTML5 Canvas
- JavaScript ES6 Modules
- WhiteNoise (статические файлы)

## Локальный запуск

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Откройте http://127.0.0.1:8000/
