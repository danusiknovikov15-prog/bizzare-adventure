# 🚀 Инструкция по публикации на Replit

## Метод 1: Загрузка через веб-интерфейс

### Шаг 1: Создайте Repl
1. Откройте https://replit.com
2. Нажмите **Sign Up** (или **Log In** если уже есть аккаунт)
3. Нажмите **+ Create Repl**
4. Выберите **Python** из списка языков
5. Введите имя: `gojo-platformer`
6. Нажмите **Create Repl**

### Шаг 2: Загрузите файлы проекта
1. Удалите файл `main.py` который создался автоматически
2. Нажмите на **три точки** (⋮) рядом с "Files"
3. Выберите **Upload folder**
4. Загрузите всю папку вашего проекта

**ИЛИ** загрузите файлы вручную:
- Перетащите все файлы и папки из вашего проекта в окно Replit

### Шаг 3: Установите зависимости
В **Shell** (внизу экрана) введите:
```bash
pip install -r requirements.txt
```

### Шаг 4: Запустите проект
Нажмите большую зелёную кнопку **Run** вверху

### Шаг 5: Откройте в браузере
После запуска откроется окно справа с вашей игрой!

---

## Метод 2: Через GitHub (продвинутый)

### Шаг 1: Загрузите проект на GitHub
1. Создайте репозиторий на GitHub
2. Загрузите туда все файлы проекта

### Шаг 2: Импортируйте в Replit
1. На Replit нажмите **+ Create Repl**
2. Выберите **Import from GitHub**
3. Вставьте URL вашего репозитория
4. Нажмите **Import from GitHub**

### Шаг 3: Запустите
Нажмите **Run**

---

## 🌐 Публикация (Deployment)

После того как проект запустился локально в Replit:

1. Нажмите на вкладку **Deployments** слева
2. Нажмите **Deploy**
3. Выберите тип: **Autoscale** (рекомендуется) или **Reserved VM**
4. Нажмите **Deploy**

Ваша игра будет доступна по постоянной ссылке типа:
`https://your-repl-name.username.repl.co`

## ⚙️ Настройки окружения (если нужно)

В разделе **Secrets** (замок слева) можно добавить:
- `DEBUG=False` - для продакшена
- `SECRET_KEY=ваш-секретный-ключ` - для безопасности

## ❗ Возможные проблемы

### Ошибка "Port 3000 is already in use"
- Перезапустите Repl (кнопка Stop, потом Run)

### Статические файлы не загружаются
Запустите в Shell:
```bash
python manage.py collectstatic --noinput
```

### База данных пустая
Запустите миграции:
```bash
python manage.py migrate
```
